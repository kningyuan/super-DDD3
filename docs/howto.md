# super-DDD3 操作与维护手册

## 安全须知

在使用本设备前，请务必阅读并理解以下安全要求：

- **严禁**在密闭空间或通风不良处运行发电机，防止一氧化碳中毒
- **必须**可靠接地，接地电阻 ≤ 4Ω
- **禁止**在燃油加注过程中启动发动机
- **必须**佩戴防护眼镜和手套进行维护操作
- **确保**燃油储存符合当地消防规范
- **远离**火源、热源和易燃物

## 首次使用准备

### 燃油加注
使用 **92# 以上无铅汽油**，严禁掺混柴油、甲醇或其他添加剂。

1. 将设备置于**水平、通风**的地面
2. 清洁燃油盖周围，防止杂质落入
3. 使用随附漏斗，缓慢加注
4. **加注量不超过油箱容量的 80%**（约 9.6L），留出热膨胀空间
5. 拧紧燃油盖，擦拭溢出的油液

⚠️ **重要**：燃油加注时必须**严禁烟火**。

### 机油检查与添加
设备出厂时机油已预装，但长途运输可能导致泄漏或下降。

1. 将发电机置于**水平**位置
2. 拔出机油尺，用干净布擦净
3. 重新**完全插入**后再拔出，检查油位
4. 油位应在**标尺的上下刻度线之间**
5. 如不足，添加 **SAE 10W-30 四冲程机油**至刻度中间

### 电池检查
设备使用免维护铅酸电池，出厂已充电。

- 检查电池接插件是否牢固，无松动
- 测量电池电压（可选），静置 2 小时后应 ≥ 12.6V
- 如电压低于 12V，需使用外接充电器充电

## 启动与运行

### 控制面板说明

| 开关/按钮 | 功能说明 |
|-----------|----------|
| 燃油开关 | 控制燃油供给，运行时必须 ON |
| 电路开关 | 控制输出，启动前先 OFF |
| 启动按钮 | 绿色，按下启动电机 |
| 停止按钮 | 红色，紧急停机或正常关机 |
| 电压选择 | 220V/110V 输出切换 |
| 油量表 | 显示燃油剩余量 |
| 充电指示灯 | 电池充电状态 |

### 启动步骤

1. **预设控制面板**：
   - 燃油开关 → **ON**
   - 电路开关 → **OFF**
   - 电压选择 → 根据负载选择

2. **按下绿色启动按钮**：
   - 首次启动可能需 3-5 秒
   - 成功后绿灯常亮，发动机运转平稳

3. **预热**：空载运行 **2-3 分钟**

4. **逐步加载**：
   - 先开启小功率负载（如照明、手机充电）
   - 逐步增加到大功率负载（空调、电焊机等）
   - 避免瞬间大电流冲击

### 正常停机

1. 关闭所有负载开关
2. 按下红色 **停止按钮**
3. 等待发动机完全停止（约 10 秒）
4. 将燃油开关拨至 **OFF** 位置

**紧急停机**：直接按下红色按钮，无需按步骤。

## 日常监控与异常处理

### 仪表读数监控
- **频率表**：应稳定在 50Hz ± 0.5Hz
- **电压表**：220V ± 5%（负载变化时允许波动）
- **油量表**：低于 1/4 时应及时补充燃油
- **运行小时计**：记录累计运行时间，作为保养依据

### 常见异常及处理

| 现象 | 可能原因 | 处理措施 |
|------|---------|---------|
| 排气冒黑烟 | 负荷过大/空滤堵塞 | 减小负载或清洁空滤 |
| 发动机过热 | 散热不良/冷却系统故障 | 停机检查散热片、风扇 |
| 输出电压不稳 | 负载波动/调速器问题 | 检查负载突变，持续不稳需检修 |
| 启动困难 | 燃油不足/机油不足/火花塞脏 | 按顺序检查，必要时联系维修 |
| 异常噪音 | 螺丝松动/减震垫老化 | 停机检查紧固件和减震部件 |

### 故障代码
显示屏出现错误代码时：

| 代码 | 含义 | 处理建议 |
|------|------|----------|
| E001 | 机油压力低 | 立即停机，检查机油量，联系维修 |
| E002 | 冷却液温度高 | 检查散热片是否堵塞，环境温度 |
| E003 | 燃油系统故障 | 检查燃油管路、滤清器 |
| E004 | 充电系统异常 | 检查电池、发电机、调压器 |
| E005 | 转速传感器故障 | 需专业维修 |
| E006 | 通信模块故障 | 重启或恢复出厂设置 |

**注意**：E001、E002 为严重故障，必须立即停机。

## 定期保养计划

### 每 50 小时（或每月）
- 清洁空气滤清器外壳，检查滤芯
- 检查火花塞，清洁电极间隙（标准 0.7-0.8mm）
- 检查所有螺丝螺母是否松动
- 检查电池（如可维护，检查电解液）

### 每 100 小时（或每年）
- **更换机油**（首次在 20 小时后）
- 更换机油滤清器
- 检查并调整气门间隙（标准 0.15mm）
- 检查燃油管路老化情况
- 清洁散热片和消音器

### 每 500 小时（或每 5 年）
大修保养，包括：
- 更换所有密封件
- 检查曲轴连杆机构磨损
- 校验喷油系统压力
- 全面电气系统检查

### 长期存放（>1 个月）
1. 排空燃油箱和油管中的汽油（或添加燃油稳定剂）
2. 启动发动机，运行至自动熄火，消耗完燃油
3. 拆下电池，单独存放并每月充电一次
4. 清洁机身，关键部位涂抹防锈油脂
5. 覆盖防尘罩，存放在干燥、阴凉处

## 运输与搬运

- 搬运时应使用原包装或等效保护措施
- 避免倾斜角度超过 30°
- 运输过程中应固定油箱盖，防止燃油泄漏
- 长途运输建议排空燃油
