# super-DDD3 发电机 — 数字变频智能发电机

## TL;DR
super-DDD3 是一款额定功率 3000W、峰值功率 3500W 的家用数字变频发电机，采用第三代 DDD3 数字直驱变频技术。噪音低至 58dB(A)（7米处），纯正弦波输出（THD < 3%），支持汽油/LPG 双燃料切换，一键遥控启动，续航 4.5 小时（满负载），重量 21.5kg。

## 核心技术
- **DDD3 数字变频** — MCU 实时负载感知，低负载自动降速，省油 40%+
- **纯正弦波输出** — THD < 3%，可安全为精密电子设备供电
- **超静音设计** — 58dB(A) 比传统发电机低 12-15dB
- **CO 监测熄火保护** — CO 浓度超标 2 秒内自动熄火
- **汽油+LPG 双燃料** — 无缝切换，LPG 模式排放降低 35%

## 品牌释义
"super" 代表超级可靠，"DDD3" 代表第三代 Digital Direct Drive 数字直驱变频技术。"super-DDD3" 即为超级可靠的第三代数字变频发电机。
